=================================================================
  HOW TO CREATE ZIP FILE FOR CODESTER SUBMISSION
=================================================================

STEP 1: WHAT TO INCLUDE IN ZIP
-------------------------------
✅ Include:
  • All source code (apps/, packages/, infra/)
  • All .md documentation files
  • package.json files
  • docker-compose files
  • .env.example files
  • .gitignore
  • All configuration files

❌ EXCLUDE from ZIP:
  • node_modules/
  • .git/
  • .next/
  • dist/
  • build/
  • coverage/
  • *.log files
  • .DS_Store
  • Thumbs.db
  • apps/api/prisma/generated/

STEP 2: CREATE THE ZIP
-----------------------
Option A: Using Windows Explorer
1. Select the entire "CRM project" folder
2. Right-click → Send to → Compressed (zipped) folder
3. Rename to: nexacrm-v1.0.0.zip

Option B: Using Command Line
cd "C:\Users\LAP ZONE"
powershell Compress-Archive -Path "CRM project" -DestinationPath "nexacrm-v1.0.0.zip" -CompressionLevel Optimal

Option C: Using 7-Zip (Recommended)
1. Right-click "CRM project" folder
2. 7-Zip → Add to archive
3. Set:
   - Archive format: zip
   - Compression level: Maximum
   - Name: nexacrm-v1.0.0.zip

STEP 3: VERIFY THE ZIP
-----------------------
1. Extract ZIP to a test folder
2. Check that all files are present
3. Verify no node_modules/ included
4. Check documentation files are readable
5. Test installation:
   - cd to extracted folder
   - npm install
   - Check if it works

STEP 4: FINAL CHECKLIST
------------------------
Before uploading to Codester:

□ ZIP file size < 50MB (without node_modules)
□ All documentation files included
□ README.md is clear and complete
□ INSTALLATION.md has step-by-step guide
□ LICENSE.md properly formatted
□ No personal information in code
□ No API keys or secrets in code
□ .env.example files present (no real credentials)
□ All features documented
□ Screenshots/demo video prepared separately
